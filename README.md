# CG Policy Games

เกมกิจกรรม CG 2 เกม เปิดเล่นในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้ง

- `crack-the-code.html` — Activity 1: Crack the Code (15 ชุด ชุดละ 5 คำ สำหรับ 6 ทีม · รอบที่ 1 ทีมละ 60 วินาที · รอบชิงชนะเลิศ 30 วินาที)
- `policy-survivor.html` — Activity 2: Policy Survivor รู้จริง ต้องรอด! (30 คำถาม แข่งเดี่ยว)
- `index.html` — หน้าเมนูเลือกเกม

## คีย์ลัด
- Crack the Code: `Enter` ถูก · `S` ข้าม · `A` เฉลย · `Space` หยุด/เล่นต่อ
- Policy Survivor: `Space` จับเวลา · `R` เฉลย · `→` ข้อต่อไป · `←` ย้อนกลับ
